# triangle-free-process

Beginner’s notes on the current state-of-the-art lower bound for the Ramsey number \(R(3,k)\).

**Is [arXiv:2510.19718](https://arxiv.org/pdf/2510.19718) SOTA?**
Yes for the *lower* bound: \(R(3,k)\ge(\tfrac12+o(1))k^2/\log k\).
The matching *upper* bound \(R(3,k)\le(1+o(1))k^2/\log k\) is still Shearer (1983).

Read [`SOTA-GUIDE.md`](SOTA-GUIDE.md): definitions from zero, the problem statement, and the theorems with proofs written for a master’s student.
